# Jaan Broast & Biryani — Next.js Website

Production website for **Jaan Broast & Biryani**, Quetta. Built with Next.js 15 (App Router), TypeScript, Tailwind CSS v4, and `next-intl` for English / Urdu (RTL).

## Quick start

```bash
npm install
npm run dev          # http://localhost:3000  → redirects to /en
```

Open `/en` for English and `/ur` for Urdu. Layout flips RTL automatically on `/ur`.

## Production

```bash
npm run build
npm start            # serves the optimized build on http://localhost:3000
```

Deploy to **Vercel**: push the project to a git repo, import it on vercel.com — zero config needed.

## What lives where

```
app/                 # Next.js App Router
  globals.css        # ← THE THEME LIVES HERE (colors, fonts, radii, shadow)
  layout.tsx         # pass-through root
  [locale]/
    layout.tsx       # html/body, fonts, JSON-LD, metadata per locale
    page.tsx         # composes the homepage sections
  sitemap.ts         # auto-generates sitemap.xml
  robots.ts          # auto-generates robots.txt

components/
  layout/            # Header, MobileDrawer, Footer, LanguageSwitcher
  sections/          # Hero, Marquee, Categories, SignatureDishes, ...
  ui/                # Button, SectionHeader, Tag, Container

data/                # ALL EDITABLE CONTENT
  site.ts            # brand name, address, phones, hours, social links
  categories.ts      # 8 category cards
  dishes.ts          # signature dishes with prices
  menu.ts            # full menu items + filter tags
  offers.ts          # deals/specials
  reviews.ts         # testimonials + aggregate rating
  whyChoose.ts       # value props
  orderChannels.ts   # order method cards

i18n/
  routing.ts         # locale config: en, ur (default = en)
  request.ts         # next-intl request loader
  navigation.ts      # locale-aware Link / useRouter
  messages/
    en.json          # English copy
    ur.json          # Urdu copy

lib/
  seo.ts             # buildMetadata helper (Open Graph, hreflang, robots)
  jsonld.ts          # Restaurant + Menu + AggregateRating schema.org

middleware.ts        # next-intl locale detection
public/              # static assets (logo.png)
```

## How to change things

### 1. Brand colors / fonts (one file)

Open **`app/globals.css`** — at the top is an `@theme { }` block. Change any `--color-*` value and the whole site rebrands. See `theme/README.md` for examples.

### 2. Phone numbers, hours, address

Edit **`data/site.ts`**. Affects header, footer, location section, JSON-LD, and the sitemap.

### 3. Menu items

Edit **`data/menu.ts`**. Each item is `{ num, name: { en, ur }, desc: { en, ur }, tags }`. The filter chips are driven by `tags`.

### 4. Prices on signature dishes / offers

Edit **`data/dishes.ts`** and **`data/offers.ts`**. Prices flow into Schema.org `MenuItem` JSON-LD too.

### 5. Translations

Edit **`i18n/messages/en.json`** and **`i18n/messages/ur.json`**. Anything that's a heading/CTA/section copy lives here. Anything that's structured content (menu items, offers, etc.) lives in `data/*.ts` with `{ en, ur }` fields.

### 6. Add a new menu filter category

1. Add the new tag to the `MenuTag` union in `data/menu.ts`.
2. Add it to `menuFilters` (with a `labelKey`).
3. Add the localized label under `menuPreview.filters` in both `i18n/messages/*.json`.
4. Tag the relevant menu items in `data/menu.ts`.

- `Restaurant` + `Menu` + `AggregateRating` JSON-LD injected on every page — see `lib/jsonld.ts`.

## Performance notes

- All sections render on the server. Only `MobileDrawer`, `LanguageSwitcher`, and `MenuPreview` (filter) ship JS to the browser.
- Fonts (Archivo Black, Manrope, JetBrains Mono, Amiri) are self-hosted via `next/font/google` — no Google CDN round-trip, no CLS.
- All food photography currently loads from Unsplash with `next/image` optimization. For the absolute fastest load, download the images to `public/images/` and update the URLs in `data/*.ts` — `next/image` will then serve AVIF/WebP from the same origin.
- First-load JS (homepage): ~141 kB. Lighthouse should report 95+ across Performance / Accessibility / SEO once deployed.
